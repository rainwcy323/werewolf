# 狼人殺・無法官

不需要法官（上帝視角）的狼人殺網頁 App，手機、平板、電腦都能用。

- **單機模式**：一台裝置放在桌子中央，語音播報「天黑請閉眼」，被點名的角色睜眼操作。可離線使用。
- **多機模式**：一台當主機建立房間，其他人用自己的手機輸入房號或掃描 QR Code 加入，每個人只看得到自己的資訊。需要網路（WebRTC 點對點，透過 PeerJS 公用伺服器配對）。

## 角色

共 29 種角色，涵蓋 andyventure 教學中的全部角色，另加夢魘：

- **狼人陣營**：狼人、狼王、白狼王、狼美人、隱狼、石像鬼、血月使徒、惡靈騎士、夢魘
- **神職**：預言家、女巫、獵人、守衛、白痴、騎士、訓熊師、禁言長老、攝夢人、魔術師、獵魔人、烏鴉、守墓人、占卜師
- **平民**：平民、老流氓
- **特殊／第三方**：丘比特、野孩子、盜賊、炸彈人

每種人數（6–18 人）都內建 3～13 種建議板子，共 53 種，也可以自行調整。可選警長競選。
規則參考 <https://andyventure.com/boardgame-langrensha/>、87G 狼人殺板子大全、口袋狼人殺。例外規則（同守同救、女巫自救、屠邊/屠城等）可在開局前設定。

## 本機測試

```bash
python -m http.server 8765
```

然後打開 <http://localhost:8765>。

## 讓手機也能打開（部署）

多機模式需要每台手機都能打開同一個網址，最簡單的方法：

1. **Netlify Drop**：到 <https://app.netlify.com/drop>，把整個資料夾拖進去，會得到一個 https 網址。
2. **GitHub Pages**：把資料夾推到 GitHub repo，在 Settings → Pages 開啟。

只要有 https 網址，單機模式也能直接在手機上使用（可「加入主畫面」當 App 用）。

## 注意事項

- 主機裝置在遊戲中必須保持畫面開啟、不要關閉分頁（遊戲狀態存在主機上）。
- 建議所有裝置連同一個 Wi‑Fi；部分電信行動網路之間可能無法建立點對點連線。
- 玩家斷線後重新整理頁面，會自動以同一身分回到遊戲。

## 檔案結構

| 檔案 | 用途 |
| --- | --- |
| `js/roles.js` | 角色定義、建議板子、預設規則 |
| `js/engine.js` | 遊戲流程引擎（夜晚、白天、警長、投票、死亡技能、勝負判定），單機與多機共用 |
| `js/ui.js` | 畫面元件、語音播報、設定編輯器、規則說明 |
| `js/single.js` | 單機模式 |
| `js/multi.js` | 多機模式（主機／玩家、PeerJS 連線） |
| `js/app.js` | 首頁與路由 |
